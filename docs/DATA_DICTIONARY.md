# SwasthAI Data Dictionary

## Core Clinical & Pipeline Entities

### 1. Patients Table (`patients`)
- `id` (VARCHAR): Primary key UUID (`pat-...`).
- `phone_hash` (VARCHAR): One-way SHA-256 hash of patient contact number. Plaintext phone numbers are never persisted.
- `aadhaar_hash` (VARCHAR): One-way SHA-256 hash of national identification number.
- `pseudonym_id` (VARCHAR): Anonymized village healthpod display identifier (e.g. `SATNAVARI-A4F90B`).
- `age` (INTEGER): Patient age in years [0-125].
- `sex` (VARCHAR): Biological sex (`MALE`, `FEMALE`, `OTHER`, `UNKNOWN`).
- `is_pregnant` (BOOLEAN): Pregnancy flag used for medication contraindication logic.

### 2. Consultations Table (`consultations`)
- `id` (VARCHAR): Primary key UUID (`enc-...`).
- `patient_id` (VARCHAR): Foreign key referencing `patients.id`.
- `status` (VARCHAR): Consultation status (`IN_PROGRESS`, `EXTRACTED`, `VERIFIED`, `EMERGENCY_HALTED`, `DIAGNOSED`, `CLINICIAN_REVIEWED`).
- `primary_hypothesis` (VARCHAR): Diagnostic hypothesis generated by the CDSS.
- `differential_hypotheses_json` (TEXT): JSON array of differential diagnoses.
- `reviewed_by_clinician` (BOOLEAN): Mandatory physician attestation flag.

### 3. Vitals Table (`vitals`)
- `systolic_bp` (REAL): Systolic blood pressure in mmHg (physiologic bounds: 40-300).
- `diastolic_bp` (REAL): Diastolic blood pressure in mmHg (physiologic bounds: 20-200).
- `heart_rate` (REAL): Pulse / heart rate in bpm (physiologic bounds: 20-250).
- `respiratory_rate` (REAL): Breaths per minute (bounds: 5-80).
- `temperature_c` (REAL): Core temperature in degrees Celsius (bounds: 30.0-45.0).
- `spo2` (REAL): Peripheral capillary oxygen saturation in percentage (bounds: 40.0-100.0).
- `blood_glucose_mg_dl` (REAL): Random or fasting glucose in mg/dL (bounds: 10-1000).

### 4. Lab Results Table (`lab_results`)
- `analyte_name` (VARCHAR): Extracted test name from report or entry.
- `numeric_value` (REAL): Normalized quantitative measurement.
- `unit` (VARCHAR): Canonical measurement unit.
- `loinc_code` (VARCHAR): Verified LOINC code (e.g., `718-7` for Hemoglobin, `777-3` for Platelets, `2160-0` for Creatinine).
- `verification_status` (VARCHAR): Deterministic status (`VERIFIED`, `NEEDS_REVIEW`, `UNRESOLVED`, `INVALID_UNIT`, `IMPLAUSIBLE`, `INCOMPLETE`).
- `plausibility_flag` (VARCHAR): Clinical classification (`NORMAL`, `HIGH`, `LOW`, `CRITICAL_HIGH`, `CRITICAL_LOW`).

### 5. Extracted Symptoms Table (`extracted_symptoms`)
- `canonical_concept` (VARCHAR): Standardized clinical symptom concept.
- `original_phrase` (VARCHAR): Matched source token.
- `language` (VARCHAR): Source language code (`en`, `hi`, `hinglish`).
- `is_negated` (BOOLEAN): Negation polarity flag (True if negated, False if affirmed).
- `extraction_method` (VARCHAR): Extraction algorithm (`LEXICON_EXACT`, `RATCLIFF_OBERSHELP`, `LLM_FALLBACK`).

### 6. Safety Events Table (`safety_events`)
- `rule_id` (VARCHAR): Deterministic safety rule identifier.
- `severity` (VARCHAR): `CRITICAL`, `WARNING`, `INFO`.
- `trigger_observed_value` (VARCHAR): Input value that triggered the alert.
- `trigger_threshold` (VARCHAR): Threshold configured in the ruleset.
- `circuit_breaker_halted` (BOOLEAN): Indicates if generative reasoning was aborted.
