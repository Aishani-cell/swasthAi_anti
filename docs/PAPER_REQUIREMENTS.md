# SwasthAI — Research Paper Requirements & Traceability Matrix

## Reference Publication
- **Title**: *SwasthAI: A Privacy-Preserving Neuro-Symbolic Multi-Agent AI Framework for Multimodal Diagnosis and Drug-Class Recommendation in Rural Healthpods*
- **Authors**: Aishani Bhatnagar (BIT Durg), Bushra Ameen (BIT Durg), Santosh Kumar (IIIT-Naya Raipur)
- **Target Context**: ITU-T Recommendation Y.4218 Smart Village Primary Healthcare (Satnavari, Maharashtra, India)
